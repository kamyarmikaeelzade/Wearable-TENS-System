# ⚡ Wearable TENS System

### A textile-integrated Transcutaneous Electrical Nerve Stimulation research prototype with MATLAB-based waveform modeling and wearable electrode design.

---

## 🧠 Overview

**Wearable TENS System** is a biomedical engineering project focused on the design and development of a wearable electrical stimulation platform based on **Transcutaneous Electrical Nerve Stimulation (TENS)**.

The project explores the integration of electrical stimulation technology with a wearable garment structure, allowing electrodes to be positioned directly within or on the wearable system instead of relying only on conventional standalone electrode pads.

In addition to the wearable hardware concept, **MATLAB** is used for stimulation waveform modeling, signal analysis, visualization, and evaluation of stimulation parameters.

The main goal of the project is to study how TENS technology can be integrated into a more wearable, reusable, and engineering-oriented platform for research and prototyping.

---

## 🎯 Project Objectives

- Design a wearable TENS prototype
- Integrate stimulation electrodes into a wearable structure
- Model TENS electrical waveforms in MATLAB
- Study stimulation frequency and pulse characteristics
- Analyze electrical stimulation signals
- Investigate electrode positioning and wearable usability
- Develop a modular platform for future biomedical research
- Create a foundation for future smart and adaptive TENS systems

## ⚡ TENS Waveform

```text
Frequency        → Number of stimulation pulses per second
Pulse Width      → Duration of each electrical pulse
Amplitude        → Stimulation signal intensity
Session Duration → Total stimulation time
```

MATLAB can be used to visualize and compare how changes in these parameters affect the generated stimulation waveform.
